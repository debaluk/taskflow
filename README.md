# Task Management System — Core UI v1.0

Core UI siap dipasang ke project Laravel. Tidak membutuhkan npm/Tailwind; CSS vanilla dan JavaScript ringan.

## Struktur
- Dashboard
- Sidebar workspace navigation
- Task List
- Kanban Board
- Calendar
- Gantt
- Task detail drawer/modal
- Responsive layout
- Demo data di controller

## Instalasi
1. Copy isi folder ini ke root Laravel project.
2. Pastikan web server menunjuk ke `public/` Laravel.
3. Tambahkan route dari `routes/web.php` sesuai contoh.
4. Controller demo bisa dipakai dulu sebelum database/model selesai.

## Route demo
- `/tasks`
- `/tasks/board`
- `/tasks/calendar`
- `/tasks/gantt`
